- Git: 2.56.0.windows.2
- Node.js: v24.21.0
- npm: 11.19.0
- Editor: VS Code

## How I got the project
1. Cloned https://github.com/K-Avinash1/econocausal.git
2. Switched to the zahra-dev branch

## How the frontend runs
1. Open a terminal in the project folder and run `cd frontend`
2. First time only: `npm install`
3. `npm run dev`
4. Open http://localhost:5173 in the browser
5. Stop with Ctrl+C

The React app was created on 20 Oct 2026 with `npm create vite@latest frontend -- --template react`.
